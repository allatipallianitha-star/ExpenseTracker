Expense Tracker

Project Description
Expense Tracker is a Python-based application developed using SQLite. It helps users manage their income and expenses through a simple menu-driven interface.

Features
- Add Income and Expense transactions
- View all transactions
- Search transactions by ID
- Update transaction details
- Delete transactions
- Calculate total income
- Calculate total expenses
- Display current balance
- Input validation and error handling
- Date validation

Technologies Used
- Python
- SQLite
- SQL

Project Files
- "main.py" – Main application and menu.
- "database.py" – Database creation.
- "expenses.db" – Database generated when the application runs.
- ".gitignore" – Files excluded from Git.

How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python main.py
5. Follow the menu options.

Date Format
The application uses YYYY-MM-DD format.
